# 风格配置说明

## 必填字段

name, industry, topics, tone, theme

## 可选字段

target_audience, voice, writing_persona, word_count, blacklist, reference_accounts, cover_style, author

## 可用排版主题

- 通用：professional-clean, tech-modern, warm-editorial, minimal, bytedance, sspai, newspaper, bauhaus, ink, midnight, bold-green, bold-navy, elegant-rose, minimal-gold, focus-red, github
- 健康科普推荐：medical-authority-blue（医院权威蓝，专业可信/数据感）, senior-friendly-blue（大字适老蓝，面向中老年读者）, fresh-health-green（清新健康绿，步骤化/可执行）, card-module-clean（卡片模块化，清单/对比/体检解读）
- 带背景（非白底）：bg-morandi-beige（莫兰迪燕麦）, bg-cream-blue（奶油雾霾蓝）, bg-gradient-mist（弥散渐变）, bg-warm-sand（暖沙卡片）, bg-soft-mint（薄荷淡绿）, bg-rose-paper（玫瑰粉笺）, bg-ink-paper（水墨宣纸）, bg-sky-soft（天空淡蓝）, bg-lavender（薰衣草紫）, bg-grid-paper（网格纸）, bg-deep-night（深夜暗色）, bg-warm-charcoal（暖炭暗色）, bg-forest-deep（森林墨绿）
