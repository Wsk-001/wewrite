# 写作规范

## 文章结构

- H1 标题（20-28 字，核心关键词进前 12 字，见 seo-rules.md）
- 从 frameworks.md 选定框架
- 金句落点处放精炼总结句
- 配图以标准 Markdown 图片语法 `![](图片路径)` 插入到对应论点段落的下方，路径用相对文章文件的相对路径（如 `output/xxx-1.jpg`）；发布时 `toolkit/cli.py publish` 会自动上传这些图片并替换成微信图床 URL。**不要留"（此处配图）"这类占位文字，直接写图片语法**

## 开头硬约束

1. **前 100 字必须有钩子**：推荐流算法里阅读进度不足 30% 就退出会被标记低质/标题欺诈，开篇即是生死线。钩子形式：反常识观点、冲击数据、与读者强相关的问题，三选一
2. **开头第一段后接一段摘要式概述**（2-3 句，说清本文解决什么问题、给什么结论）——微信 AI 摘要（小微）会为文章生成摘要，结构清晰的文章更受益于 AI 摘要推荐
3. 核心关键词出现在正文前 100 字（搜一搜语义对齐）

## 跑题规则（与反检测 2.4 配合）

- 跑题只允许出现在**段落边界**：整段跑，跑完整段收，禁止句中插跑题
- 跑题段落结束后必须**带回新的信息增量**（新数据/新细节/新角度），让跑题成为"散步顺路捡的东西"而不是废话
- 全文跑题不超过 2 处；高频跑题会拖垮完读率，反 AI 检测的分和人味不能靠堆跑题换

## 收藏型元素

收藏率已是第三大推荐权重（约 20%），每个 H2 段落至少含一个可收藏元素：

- 带出处的数据点（账号既有特征，继续保留）
- 数字对比/速查清单/步骤表
- "先收藏再往下看"级别的高密度干货段每篇至少 1 个

## 反检测规范

### 一、统计反检测

1.1 句长方差：全文句长标准差 ≥ 15 字
1.2 词汇温度：4 种温度带（冷/温/热/野）混用
1.3 段落长度节奏：禁止连续 2 个相近长度段落
1.4 情绪极性分布：负面情绪句占比 5-10%（账号实测均值 6.4%），至少 2 处明确负面情绪
1.5 副词密度：每 100 字不超过 3 个
1.6 段落间风格漂移：不同 H2 段落正式度有差异

### 二、语言反检测

2.1 禁用词表：连接词、AI 惯用语、空洞形容、总结句式
2.2 破句与句法变形：每 500 字至少 3 种句法特征
2.3 意外用词：每 500 字至少 1 处
2.4 连贯性打破：硬切/跑题/非线性展开——跑题执行本文件「跑题规则」（段落边界 + 带回信息增量）

### 二·补：红旗词与 AI 结构专项（脚本硬检测）

以下三项由 `humanness_score.py` 直接命中扣分，写作时主动规避：

**（1）红旗词——AI 高频书面语/连接词，尽量 0 命中**

这些词本身没错，但它们是 AI 中文的"气味源"，出现即扣分。写作时优先用右列口语替代：

| 红旗词（避免） | 口语替代 |
|---|---|
| 因而 / 因此 / 从而 / 旨在 | 所以 / 就是为了 / 结果 |
| 鉴于 / 基于此 / 在当下 | 因为 / 眼下 / 现在 |
| 值得注意/一提的是 | 有意思的是 / 巧的是 |
| 不可忽视 / 不容置疑 / 毋庸置疑 | 别小看 / 真不是吹的 |
| 归根结底 / 从本质上讲 | 说到底 / 往根上说 |
| 由此可见 / 不难看出 / 足见 | 这么看 / 说白了 |
| 事实上 / 实际上 / 毋庸置疑 | 讲真 / 老实说 |

**（2）否定对举——"不是 X，而是 Y"最多 1 次**

这是 AI 中文头号痕迹结构，同类还有"不在于…而在于…""不仅…而且…"。偶发 1 次无妨，**反复出现即为手印**。想表达对比时，直接两项并列陈述，或先给事实再给判断，别用"否定—纠正"的壳。

**（3）修辞公式化——三段式排比/虚假范围最多 1 次**

- 三段式排比："不仅 A，而且 B，更重要的是 C"——每段都用就是指纹，两项优于三项
- 虚假范围："从 X 到 Y，从 A 到 B"——除非确有跨度，否则删
- 修正法：删掉排比的第三项；把"不仅…而且"改成"而且""更别说"；后半句是废话就整句删

**（4）破折号——尽量少用**

破折号（——）是 2025 年"AI 误判"事件的标志符号：多位真人作者因密集使用破折号被平台判为 AI。健康科普文里**全篇破折号控制在 0-2 处**，需要停顿/转折时优先用逗号、句号或口语短句（"说白了就是"）替代。注意：破折号中断句法在评分里同时算作"破句"来源，过度依赖会让节奏显得刻意。

### 三、内容反检测

3.1 真实信息锚定：每个 H2 至少 1 条真实素材
3.2 具体性注入：每 500 字至少 2 处具体细节
3.3 信息密度波浪：高密度段后跟低密度段
3.4 维度随机化：从 6 个维度池随机激活 2-3 个

## 字数控制

目标：1500-2500 字

## 结构打破清单（每篇换一种骨架）

AI 最稳定的手印是"引言→三点→总结"。**写作前先确认本篇与上一篇结构不同**；若雷同就强制换骨架。可选开头策略（与 `opening_style` 配合，每篇轮换）：

- 场景切入：从一个具体生活画面开始（不写"背景介绍"）
- 倒叙：先给反直觉结论，再回头论证
- 数据冲击：一句带出处的硬数据劈头砸下
- 第一人称插叙：先讲"我当时怎么想的"
- 问答体：抛一个读者真会问的问题，直接答

可选收束方式（轮换，避免每篇都用互动问句）：
- 生活场景互动问句（账号默认）
- 戛然而止的短句
- 用一个画面收束
- 留一个没答案的问题
- 省略总结段，让读者自己得出结论（**每 3 篇至少 1 次**）

自检：本篇的开头策略和收束方式，是否和上一篇相同？相同 → 换。
