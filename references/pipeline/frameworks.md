# 写作框架库

## 框架 A: 痛点型
适合：解决问题、提供方案的选题。
结构：开头（痛点共鸣）→ 痛点放大 → 解决方案 → 实操验证 → 结尾

## 框架 B: 故事型
适合：人物、事件、趋势类选题。
结构：开头（悬念钩子）→ 背景铺垫 → 转折与高潮 → 深度解读 → 结尾

## 框架 C: 清单型
适合：盘点、推荐、方法论类选题。
结构：开头（价值承诺）→ 清单项 1-N → 结尾

## 框架 D: 对比型
适合：选择、决策类选题。
结构：开头（选择困境）→ A 方案分析 → B 方案分析 → 对比总结 → 结尾

## 框架 E: 热点解读型
适合：新闻、事件、行业动态解读。
结构：开头（事件速览）→ 表面信息 → 深层分析 → 影响预判 → 结尾

## 框架 F: 纯观点型
适合：表达立场、反驳主流观点。
结构：开头（亮刀子）→ 为什么我这么想 → 主流观点哪里错了 → 如果我是对的 → 结尾

## 框架 G: 复盘/经验型
适合：个人实践总结、项目复盘。
结构：开头（结果先行）→ 背景和动机 → 做对了什么 → 做错了什么 → 结尾
